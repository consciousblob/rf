Just listening to a podcast from Democracy Innovators w/ Sylvain Le Bon fro Startin'blox and it covers a lot of things I was thinking about - it's great to know this already exists and is being developed.


Stuff:
- ID verification (e.g. only certain bodies/organisations can access this data), GDPR certification
- the solutions exist, it's just how to collate them into action
- many different tools for e.g. collaboratively writing legislation, synthesising all ideas, consensus, dissensus within debates
	- however, these tools are barely used - not linked with where the data actually is (e.g. social media platforms)
- moving away from monolithic centrally controlled platforms to e.g. fediverse
- email as a data space (different tools, shared protocol)
- need to consider both pushing and pulling dta (and pulling seems more tricky as requires verification/authentication)
