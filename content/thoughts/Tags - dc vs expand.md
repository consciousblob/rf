I had previously been using the #expand tag to indicate wherever I want to expand a particular thought, but now trialling the use of #dc instead, which represents [[diverge-converge]].

Why? I don't always necessarily want to *expand* notes - sometimes, I want to *contract* them, or generally refine, and so \#dc is more general and accurate.
