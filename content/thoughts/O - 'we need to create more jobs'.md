title: O - 'we need to create more jobs'
---

Actually, we need to find a better way to distribute necessary labour so each individual has less required working hours.

It aims to create work where none is necessary. If we think from this jobs-first perspective, it's easy to see why we've arrived at such a bloated economy, creating jobs for the sake of it. We need to instead think *work-first* - that is, what work actually needs doing? Then, how can we divide that between individuals effectively, accounting for differences in skills, inclinations and preferences?
