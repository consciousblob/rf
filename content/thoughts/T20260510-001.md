I think it would be useful for, with an LLM pass (over my thoughts/notes), it can assign words/topics to the thoughts and create a kind of word map, and also be able to tag thoughts with these words, but as actual tags (not wikilinks) because often, I don't have a specific wikilink for something, but it would be good to still filter thoughts by this thing. So, LLM can identify anything it things is relevant to the thought, and if that relevant thing is not a current note (so, it couldn't wikilink it in the "related" property), then it adds it as a plain/normal tag in a new "tags" field/property.
