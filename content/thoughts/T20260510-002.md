title: Improving unwieldy code libraries
---

When going through the Andrej Karpathy neural net course, at the end when he was showing the messiness of the PyTorch library, I realised this is quite a characteristic feature of open-source, human-developed libraries. So it would be good to have some kind of system (probably aided by LLM) that periodically "refactors" ? the code and looks for better ways to organise, streamline, standardise, make more readable, etc. And then present this as the "refactored library X.Y" or something. So, there is always the original if something in the refactored version doesn't work as intended, but there is the option to use this more "refined" library.

I think this thought is also relevant to [[programming]] and software engineering (if I made a note on that).
