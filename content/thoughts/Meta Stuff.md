I'm creating the [[meta]] tag/note to label any thoughts that are related to how to exist, how to do life.

I was deliberating using the [[optimal]] tag instead, to more explicitly signal the fact that these thoughts are about *optimising* existence, not just existing. But then that would encompass what "optimal" even is - so, "meta" is the more general concept/object which could be thought to contain "optimal". For example, I can use the "meta" object to hold/host discussions like these about whether/how the "optimal" tag should be used.
