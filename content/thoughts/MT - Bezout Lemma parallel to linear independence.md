title: MT - Bezout Lemma parallel to basis vectors in linear algebra
---

I just had the thought that, given a solution to an + bm = 1 only exists if gcd(a, b) = 1, this is like the idea of only being able to move in n dimensions if you have a basis with n linear independent eigenvectors. If e.g. a and b have a common factor, it's like they're linearly dependent - can never end up "in the direction" of equalling one, just like if two vectors u, v are e.g. parallel, they cannot be used to construct any vector in the x-y plane, only in a straight line.
