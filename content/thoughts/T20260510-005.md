title: Referencing LLM chats with integrated AI interface
---

In terms of the unified AI interface (names for this? I was thinking along lines of IAIE like IDE but integrated AI environment, or IAE as in integrated action environment), I think It would be so useful to be able to for example start a session, and then within that session be able to reference any chat with any LLM from the integrated environment via a unique ID to allow full documentation of any resources (including chats with LLMs) that were part of your learning/doing process/session.

I also think it would be really useful to be able to reference specific points in the chat, because chats can get really long and unwieldy and clunky really fast, so it would be great to be able to just automatically generate a kind of contents page for each chat and be able to edit this and be able to put in your own markers of particularly important points that are discussed in the chat. 

Also ability to tag chats and these tags correspond to 2nd brain notes, such as notes in Obsidian.
