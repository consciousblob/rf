This is a place to share the things I'm currently experimenting with in life and/or on this site.

---
This site is a new endeavour for me - a way to externalise/publicise/express thoughts online. At this point, it's supposed to represent an extension of my brain (a "second brain"), and so, I'm hoping that cultivating it will help me to clarify and organise my own thoughts. But as it stands, my thoughts around how to actually present my thoughts are quite all-over-the-place, and so this Experiments page is a way to trial different approaches and document/explain them as I go along, to hopefully ease any confusion that may arise from encountering and navigating this site (this includes my own confusion!).

## Current Experiments
Stuff I'm currently trying out / playing around with.

- Trying to describe what the site is like and how it's structured at any point in time
	- I will create a [[current-state]] note/page to act as an attempted description of the current state #duh of this space (the entire site) - some observations, ideas of usage, largely a means of [[ego-pacification]].
- Compost
	- In the "type" property/field of each note, one category I commonly use is "compost" - this is to represent the idea that the note is underdeveloped and/or is intended to form parts of more substantial notes / primarily be referenced, and is not a very significant stand-alone note (either because it is barely developed, or because it contains tertiary / less referenced or salient thoughts in my [[_ my_worldview|worldview]]).
	- But in addition to the compost *property*, I also want to try having a compost *section* (e.g. under a heading) in (almost) every note, where I can write snippets/ramblings that I think are probably related to that note, but don't yet know exactly where to slot. These will probably be very unwieldy and it's a given that they probably need tidying up (so the #refine tag could be considered implicitly present). This compost can be perhaps gleaned from the Stream...
	- Actually, as of [[Fri 17/04/26]], I'm trialling use of "To Integrate" instead of "Compost", as I feel it's more descriptive of the purpose of the section. So, some notes will have an initial "Compost" section (old) and some will have the new "To Integrate" version/label of this section.
- Stream
	- #expand  I want to be able to record thoughts semi-serially (serial in day/date, not necessarily time within that day), and then integrate them into relevant notes, so it's possible to see when/where thoughts emerged/evolved (and e.g. what they were evolving alongside), but also have a more parallelised representation, in being slotted into appropriate notes (and places within those notes). Yes, this will involve duplication - but duplication is not necessarily redundant (as in this case). #whatev 
- Same thing, different notes
	- I might have different notes (which sometimes represent "official pages" like this page) that serve the same (or a similar) purpose or discuss the same (or a similar) thing. This is just so I can represent different framings of the same thing, and figure out over time which framing I prefer, or whether to merge them.
	- For example, the landing home page for this site is what I would label a more "vanilla" home page, and this (the page you're currently on) is the more "eccentric" home page. For now, I'll keep the main Home vanilla so it's less overwhelming/deterring for any passing visitors and it's WAY more succinct (but obviously not as elaborate/elaborating on what the site even is).
